# Кейсы nmedia.pro — как устроено

Медиа кейсов лежат в трёх репозиториях GitHub Pages:
- nmedia-brands — «Бренд-видео» (+ site/showreel.mp4)
- nmedia-reels — «Reels»
- nmedia-motion — «Моушн-дизайн»

В каждом — `<раздел>.json` (список кейсов в порядке карусели) и папка на кейс:
cover (обложка карточки), bg (фон шапки страницы кейса), photo1–3 (материалы), video*.mp4 (ролики).

На сайте (Tilda) код блоков не менялся. В head главной, /case и /casemotion стоит кусок
`NM-MEDIA-GITHUB`: он подменяет старые адреса Beget на GitHub. Копии — в папке tilda/.
Пока он стоит, Beget сайту не нужен: если Beget оживёт, ничего не изменится.

Сборка: build.py (ffmpeg + Pillow). Ролики кладутся без пережатия; HEVC/.mov перекодируются в H.264
с визуально неотличимым качеством, т.к. часть браузеров HEVC не показывает.
